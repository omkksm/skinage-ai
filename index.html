SkinAge-AI · 피부 질환 예방효과 정량예측 AI 플랫폼

목표: 피부노화·아토피 피부염 개체(세포·마우스·인체)에서 환경·스트레스와 후보물질 처리에 따른 기전지표 · 질환 지수 · 예방효과를 AI로 정량 예측합니다.

모듈역할주요 기능
🤖 AI 예측예측 엔진 (핵심)조건 입력 → 16개 기전지표 변화와 95% 예측구간, 질환 지수, 예방률, 용량-반응·권장 농도, 후보물질 순위, 교차검증·중요도, 실험·문헌(PMID) 데이터 반영 재학습, 전사체 기전 역전 점수
🧬 SkinAge-Omics기전 발굴 (Dry-lab)RNA-seq DEG(NB-Wald), 피부노화 유전자 패널 70개, GO·KEGG·Hallmark ORA, 기존 분석과의 비교
🧫 SkinCell ProtoLab데이터 생산 (Wet-lab)피부세포 노화모델 15단계 프로토콜, 계산기 10종, 실험실 구축·운영 플래너
🎨 PigmentLab효능 정량멜라닌 정량, 티로시나제·IC₅₀(4PL), k-means AI 이미지 색소 분석

순환 구조: ProtoLab·PigmentLab에서 표준화된 실험 데이터 생산 → 데이터 허브로 학습 → AI가 다음 실험 조건(물질·농도·시점) 추천 → SkinAge-Omics로 기전 확인

질환 · 요인 · 지표
피부노화: 광노화(UV) · 산화스트레스 · 당화/내인성 노화 → MMP-1, 콜라겐, p16, SA-β-gal, IL-6, ROS, 멜라닌, 주름, 탄력, 표피 두께
아토피 피부염: 알레르겐·햅텐(DNCB·HDM·MC903) · 장벽 손상 · 산화스트레스 → TSLP, IL-4·IL-13, IgE, Filaggrin, TEWL, 가려움

검증: 정답이 알려진 기전 시뮬레이션 데이터 5-fold 교차검증 평균 R² 0.79 · 95% 예측구간 포함률 90% / 전사체: 합성 데이터 DEG 정밀도 98.5% · 연구실 엑소좀 RNA-seq에서 기존 edgeR 결과와 순위상관 1.000 · 기존 DEG 89.7% 재현 · 방향 100% 일치

한계: 현재 예측 모델은 기전 가정으로 생성한 시뮬레이션 데이터로 학습되어 있으며, 후보물질 A~E는 시연용 가상 물질입니다. 데이터 허브에 실험·문헌 데이터를 넣을수록 실제 효능 예측으로 전환됩니다.
